# Little Things — web sürümü

Küçük bir kasaba dükkânını büyüttüğün sıcacık bir dükkân oyunu. Bu depo yalnızca tarayıcıda oynanabilen derlenmiş
sürümü içerir.

**Oyna:** https://valaoss.github.io/little-things-web/

- Telefonda yatay tut. Android'de ilk dokunuşta tam ekrana geçer.
- iPhone'da Safari'de Paylaş > **Ana Ekrana Ekle** ile uygulama gibi tam ekran açılır.
- İlk açılış ~70 MB indirir; sonra tarayıcı önbelleğinden gelir.
